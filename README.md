# Threat Intelligence System

A Java-based Threat Intelligence System for collecting, analyzing, and detecting cyber threats.

## Features
- Threat data collection and analysis
- Malware / IP / Domain detection
- Real-time threat monitoring
- Dashboard for threat visualization

## Tech Stack
- Java
- Maven
- Git

## How to Run
1. Clone the repository
   git clone https://github.com/VishalRathodr/Threat-Intelligence-System.git
2. Open in IntelliJ / Eclipse
3. Build with Maven
   mvn clean install
4. Run Main.java from src
